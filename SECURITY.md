# Security policy

This repository is a mathematical research artifact, not a production cryptographic implementation.

The Rust modular-arithmetic helper is not constant-time, has not been audited, and is not intended for handling secret material. The repository does not implement a complete proof system, polynomial commitment scheme, or zero-knowledge protocol.

If you find a correctness issue that changes a mathematical statement, transform convention, test result, or formalization claim, please report it privately to:

**ali.mkhida@algorizk.xyz**

Include a minimal reproducer or the relevant theorem/indexing case when possible.
